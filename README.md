# VM Design Studio — Website (v3)

Professional website for **VM Design Studio**, a one-woman hand-embroidery (zari & aari)
couture boutique in Anand, Gujarat. Custom bridal lehengas, sarees, blouses, gowns and
bespoke pieces — made to order, shipped worldwide.

## Live
https://kaifashraff.github.io/vm-design-studio/

## What's inside (v3 · editorial luxury redesign)
- **Hero** — full-screen fashion photography with slow Ken Burns zoom
- **The House** — one-woman atelier story (designer's note + framed photos)
- **Collection** — 12 filterable pieces (Bridal / Sarees / Blouses / Gowns / Groom / Adornments)
  with per-product WhatsApp enquiry + detail modal
- **The Craft** — macro zardozi/aari photography + looping craft videos (poster fallback)
- **Bespoke** — 4-step commission process
- **Bridal Edit** — editorial masonry gallery
- **Shipping / FAQ / Instagram / Contact / Footer**
- 5 policy pages + 404, JSON-LD (ClothingStore + FAQPage), OG image, sitemap, robots

## Assets
- Photos: free-license Pexels photography (see CREDITS.md) — style references until the
  owner's own product shoot is available. Every piece is made to order.
- Videos: 3 Pexels clips, compressed (0.5–1.5 MB) with poster frames.
- Fonts: self-hosted Cormorant Garamond + Jost.
